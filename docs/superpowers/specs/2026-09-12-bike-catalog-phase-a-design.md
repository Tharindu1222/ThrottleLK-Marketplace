# Bike catalogue integration — Phase A

**Date:** 2026-09-12  
**Status:** Approved (Phase A only)

## Scope

- Extend Brand / BikeModel entities for catalogue fields
- Import `bike-catalog.seed.json` via idempotent `seed:bike-catalog`
- Brand/model search APIs
- Sell form searchable Brand → Model comboboxes + CC/category/fuel autofill
- Category mapping: Commuter → Street Bikes for public UI

## Out of scope (B–D)

Custom Other brand/model, full §13 form fields, admin catalogue CRUD, E2E suite
