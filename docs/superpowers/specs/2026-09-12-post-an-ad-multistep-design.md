# Post an Ad — multi-step sell form

**Date:** 2026-09-12  
**Status:** Approved

## Flow

1. Bike — Brand, Model, Category  
2. Specs — Year, Engine CC, Condition, Transmission, Mileage, Price  
3. Details — District, City, Description, Phone  
4. Photos — create draft → ≥1 photo required → submit for review  

Title auto: `{Brand} {Model} {Year}`. Fuel defaults to petrol (electric if category slug is electric).
